启动命令：

```bash
java -Duser.timezone=Asia/Shanghai -Xms128m -Xmx384m -jar app.jar --spring.config.additional-location=file:./application-production.yml
```

工作目录为容器 `/app`。运行环境接入 `1panel-network`，通过 `mysql:3306` 连接数据库。数据库账户仅授予本项目库的查询、插入、更新、删除权限；密码和签名密钥在服务器生成并保存在私有生产配置中，不写入文档。

生产配置关闭 `spring.sql.init` 和 `app.bootstrap-enabled`；连接池最大 5、最小空闲 1；CORS 限定为本项目访问地址。前端 `/api/` 转发到本机后端，其他页面使用 `try_files` 支持直接访问和刷新。系统防火墙与腾讯云防火墙均已放行 TCP 8096，18096 保持仅本机访问。

## 备份与回滚

本次是新建站点、Java 运行环境和独立数据库，没有替换其他业务的站点文件、容器或数据。初始静态页备份为站点下 `index-before-20260917-145926`，私有发布目录还保留 `previous-index`；修改前网关配置备份为发布目录中的 `tag-management.conf.before`。

如需撤回上线：

1. 在 1Panel 停止本项目网站和 Java 运行环境，保留迁移库及所有发布文件。
2. 如需恢复初始静态页，将当前 `index` 改名保留，再复制备份目录为 `index`；恢复前述网关配置备份，执行 OpenResty 配置检查，成功后重载。
3. 若上线后已有新增业务，先对服务器数据库制作新备份。不得直接使用本地旧快照覆盖运行后的数据库。
4. 如需重新启用本次版本，使用已校验的发布目录恢复前端和 JAR，保留当前生产配置与业务数据库，再启动并验证。
