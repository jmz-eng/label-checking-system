# 开发计划

## 1. 阶段安排

| 阶段 | 内容 | 完成标准 |
|---|---|---|
| 需求分析 | 从 PPT 提炼角色、流程、字段和异常场景 | 文档完成并能指导开发 |
| 技术选型 | 确认 React、Ant Design、Spring Boot、MyBatis-Plus、MySQL | 项目结构确定 |
| 目录设计 | 创建前后端目录、统一文档目录 | 目录清晰，不混放 |
| 数据库设计 | 编写表结构、索引和初始化策略 | 后端可自动建表 |
| 接口设计 | 定义登录、项目、任务、扫码、追溯接口 | 前后端字段一致 |
| 编码实现 | 完成权限、项目、任务、标签、扫码、审计 | 页面和接口可联调 |
| 测试验证 | 执行 Maven 构建、前端构建、核心接口验证 | 构建通过，核心流程跑通 |
| 部署准备 | 编写启动命令、环境变量、默认账号说明 | 本地可复现启动 |
| 版本更新 | 更新变更记录 | `1.0.0` 可交付 |
| 项目总结 | 记录后续优化方向 | 可进入下一版迭代 |

## 2. 第一版任务清单

- 创建 `backend` Spring Boot 项目。
- 创建 `frontend` React + Vite 项目。
- 后端实现统一响应、异常处理、认证拦截、权限注解。
- 后端实现 MyBatis-Plus 实体、Mapper、Service、Controller。
- 后端实现数据库建表脚本和默认数据初始化。
- 前端实现登录页、主布局、仪表盘、项目管理、采样任务、扫码工作台、追溯查询。
- 前端 API 请求统一封装，不在组件中直接写请求。
- 完成前后端构建验证。

## 3. 权限实现重点

- 接口必须声明权限码。
- 管理员拥有 `*` 权限。
- 技术员不能访问审计日志。
- 审计人员不能生成任务或执行扫码操作。
- 分析人员只能做录入确认和查询相关数据。

## 4. 后续优化

- 对接真实标签打印机模板。
- 支持扫码枪连续扫码模式。
- 支持 Excel 批量导入采样计划。
- 增加电子签名和复核确认。
- 增加异常样本处理流程。
- 与现有 PV 系统打通采样任务。
