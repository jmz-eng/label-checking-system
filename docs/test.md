- 采样任务生成和标签编码唯一性。
- 扫码绑定成功与失败。
- 操作核对全字段比对。
- 录入确认和审计日志写入。
- 前端路由、表单、表格和核心交互。

## 2. 核心测试用例

| 编号 | 场景 | 输入 | 期望 |
|---|---|---|---|
| TC-001 | 管理员登录 | 管理员账号和部署时配置的密码 | 返回 token 和全部权限 |
| TC-002 | 密码错误 | 错误密码 | 返回 400，提示账号或密码错误 |
| TC-003 | 未登录访问项目列表 | 无 token | 返回 401 |
| TC-004 | 技术员访问审计日志 | 技术员 token | 返回 403 |
| TC-005 | 新增项目 | 唯一项目编号 | 创建成功 |
| TC-006 | 重复项目编号 | 已存在项目编号 | 返回 409 |
| TC-007 | 生成采样任务 | 项目、动物号、时间点 | 返回唯一标签码 |
| TC-008 | 绑定正确动物号 | 标签码 + 匹配动物号 | 状态变为已绑定 |
| TC-009 | 绑定错误动物号 | 标签码 + 不匹配动物号 | 返回失败并记录 |
| TC-010 | 核对正确字段 | 项目号、动物号、时间点均匹配 | 状态变为已核对 |
| TC-011 | 核对错误时间点 | 时间点不一致 | 返回差异字段并报警 |
| TC-012 | 录入已核对样本 | 标签码 + 备注 | 状态变为已录入 |
