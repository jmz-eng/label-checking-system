## 浏览器用例

1. 操作列在窄桌面窗口可见，任务详情可打开关闭，查看操作不会提交核对。
2. 大图显示当前选中标签，支持关闭。
3. 更多记录使用动态菜单路由跳转。
4. 第十一条任务可分页访问，状态和关键词联合筛选生效。
5. 样本类型与计划采集日期联合筛选生效。
6. 扫入另一任务不自动替换预选核对依据；失败显示拦截，重扫清除旧结果。
7. 空白输入不发送请求，未绑定任务不能通过回车提交。
8. 成功核对后刷新当前任务状态，快速重复点击只发送一次请求。
9. 仅记录权限不请求任务接口，不显示可操作大图。
10. 只有任务查看权限时仍能打开详情，不请求扫码记录接口。
11. 扫码记录接口失败保留任务区域，提供重试和详情错误提示。
12. 任务接口失败时禁用大图，已加载的扫码记录仍可查看。
13. 工作台、任务、扫码、标签、追溯、异常、报表、项目、用户、菜单、权限、日志、公告共 13 个模块页面可打开，无未捕获页面异常。

测试源文件：`frontend/tests/e2e/dashboard.spec.ts`。最后一项仅为页面加载检查，不代表各模块的所有新增、编辑、发布操作均已验收。

## 运行方式

在 `F:\桌面\Tag Management\frontend` 执行：

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run build
npm.cmd run lint
```

测试通过配置临时启动本机 5175 端口，默认使用已安装的 Chrome。接口请求在浏览器侧使用固定数据响应，不访问真实业务 API；若端口已占用会报错，不复用未知进程。

在 `F:\桌面\Tag Management\backend` 执行：

```powershell
mvn test -q
```
