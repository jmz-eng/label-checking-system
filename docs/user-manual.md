# 用户使用手册

## 小标签打印（前端 1.0.5）

标签纸规格为 **宽 25 mm、高 10 mm，打印机 300 dpi**。标签采用左侧二维码、右侧项目号、动物号、时间点/样本类型及采集日期的横向布局。屏幕放大预览不等于纸面尺寸。

进入“标签预览”，点击卡片或表格行选择目标，核对右侧“当前标签”，再点击“打印当前标签”。驱动和浏览器均选择 25 × 10 mm，缩放 **100% / 实际大小**，边距为无，关闭页眉页脚；不要选择适合页面。一次只输出当前一张。

二维码解出的仍是带连字符的原始标签码。该小规格不再显示原来的装饰性一维条纹，需要用支持二维码的扫描器读取。请先试打一张，确认打印完整且能扫码，再批量使用。内容过长时系统会提示使用更大标签，不会强行缩小或截断文字。

若屏幕及打印文件能扫、实物仍不能扫，继续检查打印浓度、打印速度、打印头缺点、碳带/标签材料及驱动缩放。软件解码验证不能替代实物验收。

## 工作台修订说明（前端 1.0.4）

- 采样任务右侧“查看”打开任务详情，包含标签、项目、动物号、状态和该任务扫码记录；无记录查看权限时显示权限说明。
- 右侧“查看大图”打开当前选中标签的弹窗。“更多记录”进入账号菜单中配置的追溯页面。
- 状态、样本类型、条码／动物号／项目号搜索可组合使用；“任务采集日期”只筛选计划采集日期，不改变累计统计。
- 使用“核对”按钮选择已绑定的待核对任务，再扫描实际标签，点击“提交核对”或按回车。初始显示等待，提交后的结果以服务端反馈为准。
- “重新扫描”清空输入和旧结果。“手动输入”将焦点移到输入框，可直接输入标签码。
- 统计区显示累计任务及操作次数，重复核对会计入次数。核对人和时间来自真实扫码记录，缺失时显示短横线。
- 页面出现数据加载失败时点击重试。小标签打印规则见本页前端 1.0.5 说明。

## 1. 登录

打开系统后输入账号和密码登录。登录后系统会根据账号权限展示对应菜单。

## 2. 管理员

管理员负责系统初始化和基础数据维护。

常用操作：

- 创建项目。
- 新增用户、维护部门和状态、分配角色、重置密码。
- 检查用户角色和权限。
- 查看全部采样任务、扫码记录和审计日志。
- 处理异常账号和默认密码修改。

### 2.1 用户管理

1. 进入“系统管理 → 用户管理”。
2. 使用用户名、姓名或部门搜索用户。
3. 点击“新增用户”，填写用户名、初始密码、姓名、部门、角色和状态。
4. 点击“编辑”可调整姓名、部门、角色和启停状态，用户名不可修改。
5. 点击“重置密码”设置新密码，新密码长度为 8 到 72 位。
6. 当前登录账号不能停用自己或修改自己的角色；如需操作，应使用另一个管理员账号。

## 3. 实验技术员

### 3.1 生成采样任务

1. 进入“采样任务”。
2. 选择项目。
3. 填写动物号、组别、样本类型、时间点、计划采集日期和管号。
4. 点击“生成任务”。
5. 系统自动生成标签码。

### 3.2 打印标签

1. 在任务列表中选择任务。
2. 点击“标签预览”。
3. 核对项目号、动物号、时间点、日期。
4. 使用浏览器打印。

### 3.3 贴标绑定

1. 进入“扫码工作台”。
2. 选择“贴标绑定”。
3. 扫描标签码。
4. 扫描或输入动物号。
5. 点击提交。
6. 系统提示“绑定成功”后再进入下一管。

## 4. 操作前核对

1. 进入“扫码工作台”。
2. 选择“操作核对”。
3. 扫描标签码。
4. 输入或扫描项目号、动物号、时间点。
5. 系统提示“核对通过”才允许继续处理。
6. 如提示不一致，应停止操作并交由负责人确认。

## 5. 分析录入人员

1. 进入“扫码工作台”。
2. 选择“录入确认”。
3. 扫描标签码。
4. 填写必要备注。
5. 提交后任务状态变为“已录入”。

## 6. 审计人员

审计人员可查看：

- 扫码记录：每次绑定、核对、录入的结果。
- 失败记录：错动物号、错时间点、错项目号等。
- 审计日志：关键操作的人、时间、业务对象和详情。

## 7. 异常处理建议

| 提示 | 处理 |
|---|---|
| 标签码不存在 | 检查是否扫错标签，必要时重新打印 |
| 动物号不一致 | 暂停操作，确认管子和动物来源 |
| 时间点不一致 | 暂停操作，确认是否拿错时间点样本 |
| 当前账号无权操作 | 联系管理员调整角色或更换账号 |
| 令牌已过期 | 重新登录 |
