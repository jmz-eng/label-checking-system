# 需求规格说明书

## 1. 背景

PPT 中指出，当前采血及样品处理环节的标签为纯文字标签，核对依赖技术员逐字段肉眼比对。典型标签字段包括项目号、动物号、时间点、采集日期。样本量较大时，人工核对容易出现漏看组别、漏看时间点、整管拿错等问题。

系统建设目标不是增加人工复核，而是把核对动作从“人读文字”转为“机器比码”，在贴标、操作、录入三个关键节点完成拦截和留痕。

## 2. 项目目标

- 系统自动生成带条码/二维码的样品标签，减少手工制作标签带来的源头错误。
- 贴标时扫码确认“标签码 = 动物/采样任务”，当场完成绑定。
- 操作前扫码核对项目号、动物号、时间点、采集日期等关键字段。
- 核对不通过时立即报警并记录失败原因。
- 分析录入阶段通过扫码自动确认样本状态，减少手敲 Excel。
- 对所有关键操作保留操作者、时间、结果和差异信息，支持追溯和审计。

## 3. 用户角色

| 角色 | 职责 |
|---|---|
| 系统管理员 | 用户、角色、权限、基础数据管理 |
| 实验技术员 | 生成采样任务、打印标签、贴标绑定、扫码核对 |
| 复核/分析人员 | 查看核对通过的样本，完成录入确认 |
| 审计人员 | 查看扫码记录、审计日志和异常记录 |

## 4. 功能范围

### 4.1 登录与权限

- 用户使用账号密码登录。
- 后端返回访问令牌和权限列表。
- 后端根据权限返回动态菜单和动态路由，前端按返回结果生成侧边栏与页面路由。
- 后端对每个接口再次校验权限，不能只依赖前端菜单隐藏。
- 未登录、令牌过期、权限不足时返回清晰错误信息。

### 4.2 项目管理

- 新增项目：项目编号、项目名称、供试品、委托方、负责人。
- 查看项目列表和状态。
- 项目编号必须唯一。

### 4.3 动物与采样任务

- 根据项目创建采样任务。
- 采样任务包含动物号、组别、样本类型、时间点、计划采集日期、管号。
- 系统为每个任务生成唯一 `labelCode`。
- 任务状态支持：待打印、已打印、已绑定、已核对、已录入、已作废。

### 4.4 标签管理

- 支持按任务生成条码/二维码数据。
- 标签展示采用 PPT 第 8 页建议的双码组合样式：项目号、动物号、时间点、采集日期、条码、二维码。
- 第一版先提供页面预览和浏览器打印，后续可对接专用标签打印机。
- 提供独立“标签预览”模块，便于批量查看、筛选和打印标签。

### 4.5 扫码绑定

- 技术员扫描标签码并录入/扫描动物号。
- 系统校验标签所属任务与动物号是否一致。
- 一致则绑定成功，不一致则报警并记录失败。

### 4.6 操作核对

- 操作前扫描标签码，同时录入项目号、动物号、时间点。
- 系统进行全字段比对。
- 校验通过才允许进入后续处理。
- 校验失败时返回差异字段和处理建议。

### 4.7 自动录入与追溯

- 分析端扫描标签码后确认录入状态。
- 系统保存录入人、录入时间、备注。
- 所有绑定、核对、录入动作写入扫码记录和审计日志。

### 4.8 系统管理

- 管理员可查询、新增和编辑系统用户，并分配一个或多个角色。
- 用户名创建后不可修改；密码不得通过列表接口返回。
- 管理员可单独重置用户密码，也可启用或停用账号。
- 系统禁止当前登录用户停用自己的账号或修改自己的角色。
- 管理员可维护菜单树、路由路径、前端组件标识、图标和权限标识。
- 管理员可维护权限点、角色，并为角色分配权限。
- 有权限用户可查看系统操作日志，支持关键字检索。
- 管理员可维护系统公告，支持草稿、编辑和发布，已发布公告在工作台展示。

### 4.9 工作台与统计报表

- 工作台顶部展示今日任务、已核对、核对通过、异常拦截、待处理、追溯记录等指标。
- 工作台中部展示采样任务列表，右侧提供扫码核对和标签预览。
- 提供独立“异常拦截”模块，只展示扫码失败、标签不存在、字段不一致等记录。
- 提供独立“统计报表”模块，展示任务状态分布、扫码动作分布、通过率和异常拦截率。

## 5. 非功能需求

- 权限控制必须在后端实现，前端菜单隐藏不能作为安全依据。
- 所有接口返回统一格式：`code`、`message`、`data`、`timestamp`。
- 错误信息要能指导现场人员处理问题。
- 数据库字段命名使用小写下划线。
- 所有核心表包含 `created_at` 和 `updated_at`。
- 关键查询字段建立索引。
- 本地开发数据库密码通过环境变量或本机配置注入。

## 6. 验收标准

- 管理员可登录并维护项目与采样任务。
- 管理员可看到工作台、采样任务、扫码核对、标签预览、追溯记录、异常拦截、统计报表、系统管理模块。
- 管理员可新增用户、分配角色、停用账号和重置密码，相关操作写入审计日志。
- 技术员可生成标签、完成贴标绑定和操作核对。
- 错码、错动物号、错时间点会被拦截并记录。
- 分析人员只能处理已核对的样本。
- 审计人员可查看所有扫码记录和审计日志。
- 前端构建通过，后端 Maven 构建通过。
