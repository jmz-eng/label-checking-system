# 条形码标签说明

本轮将所有标签打印入口改为 CODE128 条形码。纸张仍为 25×10 mm，按 300 dpi 生成黑白 SVG；条形码在上方，下方依次显示试验编号、动物号与时间点、管标信息、采样日期。动物号与时间点合并排版，五项数据都保留。

每支管都有固定的 12 位数字编码，扫描后由系统查出完整样品信息。旧二维码内容与原始标签码保留，继续进入同一套核对规则。同管补打使用相同条形码；更正或替换新管产生新码，旧管的两种扫码身份一起作废。数字编码中的前导零必须保留。

条形码两侧保留静区，最窄模块为两个打印点；文字最低 16 个打印点。没有持久化编码或文字放不下时不能打印。历史打印快照没有条形码的，应从当前管子重新登记打印请求，不修改历史快照或猜测旧码。

数据库初始化会新增 `label_barcode` 登记表。启动阶段为现有管子与旧版采样任务登记别名，不改写既有业务内容、核对记录和打印归档。新管在创建事务内获得别名，数据库约束保证唯一性。同管编码不依赖动物号、日期或时间点的拼接。

将来迁移服务器时，完整数据库备份必须包含 `label_barcode` 及全部业务表；只迁移源码不能恢复已经打印的条形码对应关系。本轮仅更新本机开发预览，未部署服务器。屏幕和图片解码验证不能替代实际打印机、纸张及扫码设备测试。

## 用户扫码设备：得力 14881S

用户提供的包装照片确认：激光一维条码扫码器、USB 无线接收器、2.4G 无线传输、识读精度标示 ≥4 mil，明确不含屏幕码。包装未列具体支持的码制，不能仅凭这张照片确认 CODE128 已启用或实机已经可扫。

本版最窄模块为 300 dpi 的两个打印点，即 2/300 英寸 = 6.67 mil = 0.169 mm。两侧各 10 模块静区为 1.69 mm；条形码含静区约 20.49 mm，条高约 2.71 mm。尺寸设计与包装标示的 4 mil 精度相容，最终需用实际打印机打印并由该设备扫描确认。打印机型号/分辨率仍待用户补充，不能把网页 300 dpi 设计当成打印机实际分辨率。

实机验收方式：

1. 插入 USB 无线接收器，使用即时传输模式；盘点/离线存储模式可能不会马上输入到网页。
2. 从 PDF 或系统标签打印入口按实际大小/100% 打印纸质标签，不用手机/电脑屏幕测试这台激光机。
3. 在文本输入框中扫描，确认输出完整的 12 位数字及前导零，无额外前缀。网页扫码默认用 Enter 提交；没有回车后缀时可点击提交按钮，或者按设备说明设置回车。
4. 在平面纸上重复扫描后，贴到实际采血管/分装管再扫描。尽量让条码长边沿管身轴向，避免绕圆周过度弯曲、褶皱、重叠或透明胶反光。
5. 再测试芯片与采血管、来源采血管与分装管的真实输入，确认正确管通过、错误动物/日期/时间点/作废管阻断并留痕。

纸面能扫但贴管后不能扫时，应调整贴标方向或实际纸张布局；平面纸也不能扫时，应核对打印分辨率、黑度/速度、纸张及 CODE128 设置。不要把线条无限变细来补救。
