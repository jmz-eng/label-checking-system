## 撤回本次新站点

以下为维护说明，本次未执行撤回。无需修改旧8096或其他站点，也不删除新库或追溯数据：

1. 在腾讯云防火墙移除本次新增的TCP8097规则，并通过`ufw delete allow 8097/tcp`移除本机新增允许规则。
2. 将私有目录中的`gateway-internal.conf`恢复到本次新站点网关配置文件，执行`docker exec 1Panel-openresty-BSpo nginx -t`通过后，再执行`docker exec 1Panel-openresty-BSpo nginx -s reload`。
3. 如需停止新后台，执行`docker stop label-checking-system`。保留站点、数据库、账号私有文件和部署记录以便恢复；不要停止原网关、MySQL或其他容器。

后续升级先备份本次数据库及私有配置，核对目标为8097新站点，使用单独的升级流程，避免再次运行空库安装脚本。
