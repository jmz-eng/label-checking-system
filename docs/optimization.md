| OPT-004 | P1 | 初始化器默认运行并重置预置角色权限、写入演示数据 | 重启可能覆盖管理员配置，生产库可能混入演示数据 | 仅在 `APP_BOOTSTRAP_ENABLED=true` 时执行，生产默认关闭 | 已完成 |

| OPT-006 | P1 | 登录成功写入 token 后，如果菜单加载失败会残留 token | 下次刷新出现异常登录态 | 菜单加载失败时回滚 token 和认证状态 | 已完成 |

## 4. 实施顺序

1. 收紧敏感配置和数据初始化开关，避免新的不安全实例继续启动。
2. 修复动态路由与登录态同步，保证前后端权限边界一致。
3. 增加路由懒加载，降低首屏主包体积。
4. 恢复 Lint，增加后端安全单元测试。
5. 同步部署、环境、测试和更新日志，并执行完整验收。

## 5. 验收标准

- 未分配任何菜单的账号不会获得全部前端路由。
- 不配置环境变量时，本地后端可直接读取 YAML 默认值启动。
- 默认情况下不创建演示账号、演示项目和演示任务。
- 登录页不再展示或预填固定密码。
- 任意接口返回 401 后，前端立即回到未登录状态。
- `npm run lint`、`npm run build`、`mvn test`、`mvn clean package` 全部通过。
- 前端生产构建不再把所有业务页面打入同一个主包。

## 6. 后续优化

以下事项需要独立设计或引入基础设施，本轮不直接改动：

- 将浏览器 token 升级为 HttpOnly Cookie，并配套 CSRF 防护。
- 增加登录失败限流、账号锁定和服务端会话注销能力。
- 引入 Flyway 管理增量数据库迁移和外键约束。
- 为列表接口增加统一分页，避免数据增长后全量查询。
- 增加前端组件测试和登录、扫码、权限场景的 E2E 测试。
- 继续拆分 Ant Design 共享依赖；当前最大共享 chunk 约 687.63 kB，仍高于 Vite 默认提示阈值。
