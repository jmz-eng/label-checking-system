# 实验工作台入口与排版调整

用户要求继续优化当前页面美观和横向并列导航，让技术员能直观看到采血核对、血样处理核对；实验前的资料设置应分开入口，并授权“你先优化起来”。本轮按这个明确方向直接调整本机可评审版本，不部署服务器、不修改领药提醒。

采用实验工作台首页 + 分组侧栏方案。另一个可行方案是在旧页上方只加两个快捷按钮，但原有十个并列页仍然容易混淆，因此本轮采用完整分区入口。

## 页面结构

- 创建/进入/切换实验默认进入工作台首页；顶部简洁呈现实验编号、名称和实验切换，保留创建实验入口。
- 首页主要视觉是两个大操作卡片：采血核对（芯片→采血管）与血样处理核对（来源采血管→分装管）。点击进入现有核对页，仍要选日期、时间点和用途才能开始；入口点击本身不创建核对会话。
- 实验内导航分三组：现场核对（工作台、两种核对）、实验准备（分组关系、用途配对、附件导入、采血管、分装管、标签打印）、追溯记录（核对记录、更改记录）。取消十个同级横排标签页。
- 当前账号失败未处理的轮次保持醒目提示和返回入口；在同实验首页可继续已有核对，不将资料数量、最近成功记录或导航动作当成新核对成功。
- 首页次要区域提供真实资料数量与准备/追溯快捷入口，数量不等于资料完整或流程通过。未加载/加载失败不显示虚假可用状态。

## 视觉与交互

- 以白色面板、浅灰底色和蓝/青色主要操作为基础，统一圆角、边框、字号和间距；减少重复标题和说明占据首屏。
- 桌面使用安静的分组侧栏 + 宽主内容区。窄屏可堆叠/收起辅助导航，两个核对入口与扫描输入仍清晰可操作；页面本身无横向溢出，数据表可在自身区域滚动。
- 键盘可操作，有可见焦点；导航标示当前位置；禁用入口说明权限原因；不只通过颜色区分入口或通过/失败。
- 核对页优化条件、状态、扫码区的视觉层次，只改容器及样式，不更改扫描条件、失败门禁、请求重试和刷新恢复逻辑。

## 保留与验证

- 保留所有现有 `?experiment=...&tab=...` 深链接、返回当前失败核对、刷新和浏览器前进/后退，未知/缺失tab回工作台。
- 保留权限、未确认请求的身份及状态、资料刷新保护、完整打印布局和历史内容；不改变后台接口及数据。
- 新导航、首页默认入口、权限、跨实验失败返回、移动端与键盘测试；完整前端回归、lint/build；桌面/窄屏实际渲染截图检查。沿用独立5175模拟浏览器测试，不绕过既有真实5174浏览器工具访问限制。
- 当前专用开发分支留给用户继续评审；本轮不自动推送GitHub或部署服务器。
